### Six things that are easy to get wrong

1. Run doc and policy scripts with `.venv/bin/python`. They need pyyaml, a system
   interpreter lacks it, and PEP 668 blocks adding it there.
2. Never edit a generated block. Change `docs/registry.yaml` or the source, then
   `make doc-sync`.
3. The security threshold is zero findings **that have a published fix**, not zero
   findings. ADR-0018.
4. No screen formats a number. Everything goes through `Figure`. `docs/12-UI-DESIGN.md`.
5. **Confirm a guard by making it fail**, not by reading it. The import contracts
   passed for weeks while enforcing nothing, and on 2026-09-27 a whole day of bar
   tracks rendered transparent because four CSS tokens did not exist and nothing
   checked that a token read was a token declared.
6. A count that comes from the repository is computed by the command that writes it
   down. Never from memory, and never by arithmetic on a count taken earlier.
