AWS-0054hub/alb.tfPLACEHOLDER-security2026-11-27The plain HTTP listener serves only when certificate_arn is empty, which is development. With a certificate it does nothing but redirect to HTTPS with a 301. Production cannot be applied without a certificate: a precondition in alb.tf fails the plan, because "we will add TLS before we go live" is a sentence that survives going live. The scanner reads the dynamic block statically and cannot see the precondition.
AWS-0053hub/alb.tfPLACEHOLDER-security2026-11-27The load balancer is internet facing because Meter is a web product that people sign into from a browser. It is the only resource in the hub with a public address, every task sits in a private subnet with no route to the internet, and the tasks accept traffic from this security group only. Making it internal would mean the product is not reachable, which is not a fix.
AWS-0132hub/storage.tfPLACEHOLDER-security2026-11-27S3 server access logging cannot deliver to a bucket encrypted with a customer managed key. The delivery is performed by the S3 log delivery group, which has no grant on the key and cannot be given one. The choice is SSE-S3 on the log bucket or no access log at all, and no access log is worse. The data bucket it logs uses the customer managed key.
AWS-0343hub/database.tfPLACEHOLDER-security2026-11-27Deletion protection is set to var.env == "prod", so production has it and development does not. A development cluster that cannot be destroyed is a development cluster somebody works around by creating a second one. The scanner evaluates the conditional statically and reports the development branch.
